# iOSキーボードの基本設計

Date: 2026-10-08 / Status: 基本方針は決定、OSS・保存方式の採用は実機確認待ち

## Context
iPhoneのオフライン日本語フリック入力を新規開発する。今回は文書設計のみ。

## Decision
本体は設定・辞書管理、Extensionは入力・変換・ホスト編集を担う。
基本入力はフルアクセスなしで成立させる。通常変換エンジン単体利用を第一候補とする。
詳細・根拠の正本は [技術構成](../docs/04-TECH-STACK.md) と [保存設計](../docs/03-ARCHITECTURE.md)。

## Reason
変換技術を再利用し、独自の修正操作とレイアウトに集中できる。権限に依存する将来機能を基本入力から分けられる。

## Alternatives
azooKey全体fork、SKK系移植、SwiftData保存を比較した。比較は技術構成文書を参照。

## Consequences
フリックUIと編集状態は自作する必要がある。採用版のmanifest・ライセンス・実機性能を確認して選定を確定する。
クリップボードは手動取込を前提とし、常時監視を要件にしない。
