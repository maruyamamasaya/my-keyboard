# 要件

## 優先度と初期範囲
P0は基本入力MVP（Phase 1〜2）、P1は操作性・カスタマイズ（Phase 3〜4）、P2は将来の履歴機能（Phase 5）。
実装・検証の状態は [開発状況](09-DEVELOPMENT-STATUS.md) で管理する。P0の安定性確認を優先し、P1・P2を初期リリースの必須条件にしない。

## 機能要件
| ID | 要件 | 優先度・フェーズ | 受け入れ条件 |
| --- | --- | --- | --- |
| IN-01 | 日本語12キーのフリック、濁点・半濁点・小書き文字 | P0・2 | タップ／各方向の読みが一致し、キャンセルで誤入力しない |
| IN-02 | 英字・数字・記号、ひらがな・カタカナ変換 | P0・2 | モード変更と候補確定が正しく、未確定文字を消失しない |
| IN-03 | 漢字変換、候補表示・選択・確定 | P0・2 | 同梱辞書だけで動き、古い候補が新しい入力を上書きしない |
| IN-04 | キーボード切り替え、文字削除、基本カーソル移動 | P0・1〜2 | 地球キーで切り替え、削除・左右移動がホストへ反映される |
| ED-01 | 頻出語の優先表示、変換候補の学習 | P1・3 | 学習の有効／無効と削除ができる。入力全文ログは保存しない |
| ED-02 | ユーザー辞書 | P1・3 | 本体で読み・表記を追加／修正／削除し、拡張へ反映する |
| ED-03 | 誤変換修正、直前の確定の再変換 | P1・3 | 同一文書・同一文脈を確認できる範囲だけ置換する。不可時は無変更 |
| ED-04 | 単語削除・長押し連続削除 | P1・3 | 日本語境界とUnicodeを考慮し、離指・画面切替で停止する |
| ED-05 | スペースキー等のドラッグでカーソル移動 | P1・3 | スペース入力とドラッグが区別され、端で暴走しない |
| LY-01 | 高さ、キーサイズ・間隔、左／中央／右配置 | P1・4 | 最小タップ領域・表示領域を保ち、不正値は既定値へ戻る |
| LY-02 | 縦横別のレイアウト・設定保存 | P1・4 | 実際の拡張サイズで再配置し、再起動後に設定が残る |

| CB-02 | 一覧・1件ずつ挿入・削除・全削除 | P2・5 | 選択した1件だけ入力先へ挿入し、削除済み内容を復活させない |
| CB-03 | 重複排除・ピン留め・ローカル検索 | P2・5 | 完全一致で重複判定し、ピンを保持し、通信せず検索する |

## 編集と履歴の範囲
- 未確定の読みはアプリ自身が管理する。選択中候補の変更は未確定範囲に限定する。
- 確定後の再変換は直前の自分の入力を第一対象とする。任意の過去文章全体の再変換は保証しない。
- 履歴はテキストのみ。画像・リッチテキスト、常時自動収集、複数端末同期は対象外。
- 履歴保存の有効化、保存前プレビュー、保持件数・容量・期間上限を設ける。値はPhase 5で確定する。
- パスワードやトークンを自動判定して必ず除外できるとは約束しない。保存は本人が判断できるようにする。

## 非機能要件
| 項目 | 方針・検証 |
| --- | --- |
| オフライン | 初回起動・変換・辞書・履歴を機内モードで確認。ネットワーク呼び出しと同期機能を含めない |
| 遅延 | タッチ→描画／確定、読み更新→候補のp50/p95、冷起動を測定。Phase 2で数値目標を設定 |
| メモリ | 辞書初期化・長文・連続入力のピークを実機測定し、キャッシュと入力長を制限 |
| 安定性 | 拡張終了・ホスト切替・回転・権限取消・保存中断から復旧し、文章の破壊を避ける |
| データ保護 | [保存設計](03-ARCHITECTURE.md)に従い、ログへ入力本文を出さない |
| バックグラウンド | 常駐・本体との常時接続・バックグラウンド監視に依存しない |
| OS互換性 | iOS 17以降を暫定候補とし、固定するOSSと実機検証で確定 |
| アクセシビリティ | VoiceOverのキー名・候補読み上げ、フリックの代替操作、コントラスト、文字拡大を検証 |
| 日本語体験 | 混在文字、句読点、連文節、固有名詞、絵文字、取消・確定・改行の一貫性を評価 |
