# プロジェクト概要

## 状態と目的
2026-10-08に策定した基本設計。初期ソースの作成後も動作検証済みではない。最新の状態は [開発状況](09-DEVELOPMENT-STATUS.md) を参照。
iPhone用の完全オフライン日本語キーボードを開発し、フリック入力の慣れを維持しながら変換・修正・レイアウトの使いやすさを改善する。

## 背景とコンセプト
文章入力では、候補選択や誤変換の修正、カーソル移動が入力の流れを妨げることがある。
Apple標準の日本語フリック入力の操作感を参考に、自分に合った配置と修正操作を提供する。標準キーボードやその変換辞書を内部から利用する計画ではない。

## 想定する利用シーン
- メッセージ、メモ、検索欄での日常的な日本語入力。
- 固有名詞をユーザー辞書に登録し、頻出語を選びやすくする。
- 片手操作や縦横の画面に合うサイズ・配置を使う。
- 将来、明示的に保存したクリップボード履歴から定型文を挿入する。

## 開発方針
- SwiftによるiOSネイティブ開発。アプリ本体はSwiftUI、キーボードの制御・ジェスチャーはUIKitを基本にする。
- Custom Keyboard Extensionで他アプリへ入力する。アプリ本体は設定・辞書・導入案内を担う。
- 通信、クラウド同期、分析SDK、実行時の辞書ダウンロードを組み込まない。必要な辞書は同梱する。
- 既存OSSの変換処理を再利用し、UIと入力状態の制御は小さな責務に分ける。
- 基本入力はフルアクセスなしで成立させ、権限が必要な追加機能は任意にする。
- 実機プロトタイプの結果で性能目標と対応OSを確定する。過度なモジュール分割は避ける。
